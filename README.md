## Project Description
A web-based Student Consultation Booking System developed to streamline academic consultation scheduling between students and lecturers. The system replaces informal WhatsApp, email, and walk-in requests with structured consultation slot creation, automated double-booking prevention, consultation mode management (Face-to-Face and Online), and real-time request status tracking.

## Key Features
- **Role-Based Authentication:** Separate dashboards and permissions for Students and Lecturers.
- **Consultation Slot Management:** Lecturers can create slots specifying date, time, consultation type (`Face-to-Face` or `Online`), venue location, or meeting link.
- **Smart Booking & Conflict Prevention:** Students can filter open slots and request consultations while the system automatically prevents double bookings.
- **Full Status Lifecycle:** Tracks consultation states across `Pending`, `Approved`, `Rejected`, and `Completed`, with self-service cancellation for students.
